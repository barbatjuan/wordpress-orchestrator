# Proposal: Plantillas reales — real starting points, a visual gate, and a native build ceiling

## Intent

The catalog produces one site with 47 names. This is measured, not felt.

| # | Measured on `main @ 123a736` | Anchor |
|---|---|---|
| 1 | 47 `TPL-*` docs (23 homes + 24 inner pages) are section lists. Only the `## 2. Wireframe` fenced block is parsed; 40 of 47 declare no wrapper shape, 54% of `## 3. Secciones` entries carry no responsive note, 88 wireframe rows are a bare id | `skills/web-templates/references/templates/**` |
| 2 | Two style lists disagree: 8 `STY-*.md` vs 5 `$ANCHORS` (`PERS-*`). Only 4 of 8 axes emit a CSS property; composition/accent/chassis/ornament are emitted as **comments** | `style-catalog/`, `_build-gallery.php:354`, `root_css_for` `:6578-6580` |
| 3 | The generated chassis carries 106 `[data-comp]` selectors and **zero** elements bearing the attribute. Card recipes are 5 hardcoded switch cases. Radii and container width are identical at every anchor; the accent is per-ground, not per-style; 1 toggle override across 67 gallery strips | `_build-gallery.php:8667-8738`, `toggles.md` (29 desynced) |
| 4 | All 80 audit rules are FORMAT rules. The framework's own overview states *"Sameness passes every rule in this repo"* | `framework-audit.php`, `skills/_wordpress-orchestrator-framework.md` |
| 5 | `shipped-log.md` and the judges' `corpus.md` are **empty**: the catalog pipeline has never recorded a real delivery. Real clients went out through the bespoke route or hand-made design | `ux-design-system/references/shipped-log.md`, `blind-judges/references/corpus.md` |

### Why this is not the style catalog with new nouns

The archived `2026-08-28-style-catalog` change widened the axis set and put the catalog in Slice 4 so
the delivery path would come first. It shipped, and the delivery path still authors from PHP: the
generator remains the author of every demo, and every gate added since measures declared shape. The
correction here is not another vocabulary — it is **removing the generator from the authoring seat**
and putting a real, hand-designed, human-approved site in the library instead, behind a perceptual
gate that a FORMAT rule cannot pass by accident.

## Scope

### In Scope

- A **Plantilla** library under `skills/web-templates/references/plantillas/<slug>/`: Canvas
  (`.dc.html` artboards, design authority) + **Maqueta** (one self-contained responsive
  `index.html`) + own photos with manifest + **Ficha** (YAML frontmatter + Mapeo nativo table) +
  **Veredicto**. Slug = fictional brand. 7–10 Plantillas, each a different **Objetivo** and
  **Enfoque**.
- A **Veredicto** gate at two levels: per-Plantilla (blind judge B + 430/768/1280 sweep of every
  page) and per-library (judge A over all covers, "same hand" grouping), both bound to a committed
  fingerprint of the bytes they judged. A stale Veredicto FAILs the audit — the discipline
  `RT_GALLERY_STALE` already has.
- **Enfoque** as vocabulary, not an engine: the 8 axes survive in Spanish as descriptive language
  for brief, ledger and judges; each Enfoque is embodied by a real Plantilla, never re-painted onto
  a chassis by tokens.
- A **native build ceiling**: `vocabulario-nativo.md` (generated by introspecting a live Elementor,
  never hand-written), a per-section Mapeo nativo in every Ficha, and `qa-review` counting HTML
  widgets and custom CSS against the Ficha's `html_widgets_max` / `css_custom_max` — default **0**.
- **Objetivo-first routing**: the recommender picks by business objective with explicit negative
  reasoning per rejected candidate, and an explicit **Ruta a medida** step when nothing fits, with a
  promotion path back into the library.
- Amputation of what the above replaces (plan §5.1), a surviving toolbox
  (`html-mockup/assets/herramientas/`), and `--clean` in both installers.

### Out of Scope

- Divi validation. The Mapeo nativo declares a Divi column; Elementor is the proven path and Divi
  stays "not validated", as today.
- The accessibility and contrast floors: they are re-measured from the Maqueta's `:root`, not moved.
- Migration of already delivered sites; `elementor-core`/`divi-core` internals; the ~55 orthogonal
  audit rules and the write-path golden.
- History rewrite. Deletions are forward-only per `config.yaml rules.proposal`; this covers the
  stale pilot branch (tip `ef4d80a`) and the client material already in `main`.
- Plantillas 8–10 sector selection (Phase 4, user's call) and the tanda-2 brands.

## Capabilities

### New Capabilities

- `plantilla-library`: the folder contract (canvas/maqueta/img/ficha/veredicto), the Ficha
  frontmatter schema, `_indice.md`, image manifest and one-shoot rules, LF-normalised fingerprints.
- `veredicto-gate`: per-Plantilla and per-library verdict format, hash staleness, the typed
  "not available" result when no browser is reachable, and the client-side half
  (`RT_LEDGER_SIN_VEREDICTO`).
- `enfoque-vocabulary`: the 8 Enfoques in Spanish, "embodied by `<plantilla>`" or "no plantilla",
  the recent-repeat advisory, and the rule that an Enfoque emits no tokens.
- `native-build-ceiling`: `vocabulario-nativo.md` by introspection, the per-section Mapeo nativo,
  and the `qa-review` count against the Ficha ceilings.
- `objetivo-routing`: Objetivo ids, negative reasoning per rejected Plantilla, the Ruta a medida
  step and its promotion path.

### Modified Capabilities

- `style-axes`: the token half is removed. The axes survive only as the descriptive vocabulary that
  `enfoque-vocabulary` inherits; `axis_matches()`, `RT_AXIS_*` and the 8-axis distinctness gate
  retire with the generator.
- `colour-and-tone-system`: reduced to measured floors carried by `herramientas/color.php` and
  `scrim.php`. The ground-family / ink-tint engine has no host once `_build-gallery.php` is deleted.
- `art-direction-ledger`: `shipped-log.md` becomes mandatory and gains a Veredicto hash + date per
  row; `RT_STYLE_REPEATS_RECENT` returns as `RT_ENFOQUE_REPETIDO_RECIENTE` (WARN, same semantics).
- `manifest-section-contract`: the `design` section persists plantilla slug + Objetivo + Enfoque;
  `STY-*` ids cease to exist.

### Removed Capabilities

- `client-chassis-generation` — there is no generated chassis; the Maqueta is derived from the Canvas.
- `gallery-bootstrap-integrity` — the gallery it protects is deleted.
- `style-catalog` — superseded by `enfoque-vocabulary` + real Plantillas.
- `bespoke-route` — superseded by Ruta a medida inside `objetivo-routing` (`RT_BESPOKE_UNDECLARED`
  keeps its id and gains Objetivo + Enfoque + sections).

## Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| **Deriving a responsive Maqueta from a Canvas is authoring, not transcription.** Measured: the delao Canvas (7 artboards, artifact `eab59854`) contains **zero `@media` rules** in 381 KB of CSS — type scales with `clamp()`, layout is fixed column counts (`repeat(3,1fr)`, `1.45fr 1fr`, a five-column filter bar) inside six `max-width:1440px` wrappers | **High** | A written derivation contract in `mockup-guide.md`; **a mobile artboard is mandatory in every Canvas**; the Veredicto sweep measures 430/768/1280 on every page |
| **A hand-written `vocabulario-nativo.md` would be wrong.** `elementor-core/references/knowledge.md:41-49` records that the native-control question was answered by introspecting a live Elementor 4.2.2 + Pro 4.2.1 across all 128 widget types, and that the from-memory answer was wrong **in both directions** | **High** | Generate it by introspection only; treat `es_kit_apply()` (`es-builder.php:3664`) carrying tokens into the global kit as what makes `css_custom_max: 0` reachable, and `grid_columns_grid` `_tablet`/`_mobile` suffixes as proof responsive grids are native |
| **Client material already sits in a public Apache-2.0 repo** and the no-history-rewrite rule forbids the usual remedy | **High** | Open Decision 1; library Plantillas never carry client photos or copy — fictional brands only |
| **Judges are self-judged**: no outside model family is reachable | **High** | `autojuzgado: sí` is written into every Veredicto; it does not block, and independence is never claimed |
| **Test churn ~250 assertions removed / ~120 added** (≈35–40% of `test-framework-audit.php`), and the coverage test compares observed ids against `ROW_TYPES` | **High** | Every new id ships with its fixture in the same PR; rules land at WARN in Phase 1 and rise to FAIL in Phase 2; the write-path golden is untouched |
| **The amputation PR exceeds the 800-line review budget by design** (~25k deleted lines) | **Certain** | Declared as mechanical deletion, marked `size:exception`, not sliced; every other PR stays inside the budget under `feature-branch-chain` |
| **The installers never delete retired files** — they overwrite in place and say so | **High** | `--clean` lands in Phase 2 **before** the redeploy; verify with `diff -rq` after each redeploy, other sessions paused |
| **Two sources of truth** (Canvas and Maqueta) drift | Med | Every change starts in the Canvas; the Veredicto binds both hashes; `RT_VEREDICTO_OBSOLETO` FAILs on drift |
| **"Native or nothing" constrains design** (veils, rule grids, `clip-path`) | Med | `vocabulario-nativo.md` is written before any Canvas; an unmappable section is redesigned, not excepted |
| **Re-judging the whole library on every entry costs ~10 min** | Med | Judge A sees covers only, one capture per Plantilla; `_biblioteca.md`'s fingerprint skips unchanged rounds |
| **Divi mapping stays unvalidated** | Med | Declared per Ficha; Elementor is the proven path |

## Rollback Plan

Branch-scoped: `feat/plantillas-reales` off `main @ 123a736`, `feature-branch-chain`, one PR per
phase slice. Revert **in reverse phase order** — reverting Phase 1 while Phase 2 stands would leave
the library with no contract and FAIL rules with no fixtures. Phase 2's deletions restore from git
(no history rewrite, ever); if Phase 2 is reverted, re-run `install` **without** `--clean` so the
restored files redeploy. Full abandonment = delete the branch; `main` is untouched and the deployed
`~/.claude` copy, which is byte-identical to `main` today, stays valid.
